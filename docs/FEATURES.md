## 当前全部使用程序占位

角色、敌人、Boss、子弹、房间、UI 和特效当前均使用矩形/色块绘制。

后续美术接入原则：

1. 不改玩法系统。
2. Entity 保留碰撞盒，额外增加 Sprite Renderer。
3. 房间从程序色块替换为 Tileset。
4. UI 从 Canvas 占位替换为像素 UI 素材。
5. 武器、道具和特效仅替换表现层。

## 暂不属于核心单机玩法范围

以下属于上线/运营能力，不应阻塞核心玩法开发：

- 微信登录
- 云存档
- 好友排行榜
- 分享
- 广告
- IAP
- 后台运营活动
- 真人联机
- 正式音乐与音效资源
- 正式美术资源

这些应在核心玩法稳定后独立接入。
