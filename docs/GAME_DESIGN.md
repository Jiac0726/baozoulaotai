# 游戏设计草案 v2

## 定位

横版像素动作 Roguelike。目标不是复刻某一具体作品，而是采用成熟的“房间推进 + 随机道具 + Build 联动”结构，并保留《暴走老太》的角色与锅具喜剧主题。

## 核心循环

进入房间 → 平台战斗 → 清怪 → 获得金币/道具 → 决定是否替换或叠加 → 开门 → 进入下一房间 → Boss → 进入下一层。

## 操作

- 左右移动
- 跳跃 / 二段跳（后续）
- 冲刺（后续）
- 主武器射击
- 近战锅具（后续）
- 互动 / 拾取

## 房间类型

1. 普通战斗房
2. 奖励房
3. 商店房
4. 精英房
5. 事件房
6. Boss 房

## Build 系统

### 武器
- 平底锅回旋炮
- 高压锅榴弹
- 锅铲激光
- 辣椒喷火器
- 保温杯连射器

### 被动道具
- 辣酱徽章：暴击附加燃烧
- 老花镜：暴击率提升
- 围裙护盾：进房获得一次护盾
- 发光拖鞋：移速提升
- 保温壶：击杀回能
- 笑脸锅贴：跳跃时向下发射弹片

## 联动目标

道具不是单纯 +10% 数值，应尽量改变攻击形态：

- 子弹数量
- 弹道
- 命中效果
- 元素状态
- 召唤物
- 跳跃/冲刺触发
- 房间清怪奖励

## MVP

- 6 个普通房
- 1 个奖励房
- 1 个 Boss 房
- 1 把基础武器
- 6 个被动道具
- 3 类普通敌人
- 1 类精英
- 1 个 Boss
- 死亡重开
