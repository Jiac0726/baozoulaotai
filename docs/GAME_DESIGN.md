# 游戏设计草案

## 定位

竖屏俯视角轻量割草 / 肉鸽。操作必须简单，但战斗中的移动、技能球争夺与路线判断要持续发生。

## 核心循环

躲避怪潮 → 观察技能球 → 冒险争夺 → 爆发清场 → 拾取资源 → 进入下一波。

## 首版技能

1. 旋风锅盖：角色周围短时间范围攻击。
2. 冲刺：向移动方向快速位移并短暂无敌。
3. 高压开锅：延迟后对大范围敌人造成高伤害。

## 首版敌人

- 小紫怪：基础追踪。
- 路锥怪：较快。
- 拆迁盾怪：高生命、慢速。
- 精英怪：带冲锋或范围攻击。
- Boss：厨神大炮 / 锅霸厨王方向，至少三阶段攻击模板。

## 地图结构

画面中间为明确的可移动战斗区域；四周布景只承担氛围和边界信息。场内只放少量真正参与战斗的障碍物。

## MVP 完成标准

- 单局 3~5 分钟
- 10 波 + 1 Boss
- 3 个主动技能
- 4 类普通敌人 + 1 精英 + 1 Boss
- EXP、金币、治疗、技能球
- 通关、失败、暂停、结算
