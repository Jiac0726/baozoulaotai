# 暴走老太

俯视角轻量割草 / 肉鸽微信小游戏原型。

## 核心玩法

- 中央战斗场地，四周为可替换布景
- 老奶奶自由移动、躲避怪潮
- 场上技能球主动争夺
- 波次刷怪、精英与 Boss
- 金币 / EXP / 临时强化掉落
- 技能构筑 + 轻局外成长

## 当前阶段

第一阶段目标是先跑通最小战斗闭环：

1. 玩家移动
2. 敌人追踪
3. 碰撞与伤害
4. 技能球拾取
5. 三个基础技能
6. 掉落与经验
7. 波次系统
8. Boss 战
9. 通关 / 失败
