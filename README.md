# 暴走老太

横版像素动作 Roguelike 微信小游戏原型。

## 新方向

项目从“俯视角割草生存”重构为：

- 横屏平台动作
- 房间推进
- 左右移动 / 跳跃 / 射击
- 武器与被动道具叠加形成 Build
- 普通房 / 奖励房 / 商店房 / 精英房 / Boss 房
- 高对比霓虹像素美术
- 奶奶 + 锅具 / 厨房武器主题

## MVP 战斗闭环

进入房间 → 清怪 → 掉落道具 → 选择/拾取 → 开门 → 下一房间 → Boss。

第一版先跑通：

1. 横向移动
2. 跳跃与重力
3. 平台碰撞
4. 基础射击
5. 敌人追击
6. 房间清怪判定
7. 奖励掉落
8. 房间切换
9. Boss 房占位
10. 通关 / 死亡重开
